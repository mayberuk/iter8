# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

For earlier history, see the git tags.

## [Unreleased]

### Added

- The Claude Code plugin and its marketplace now live in this repository: install with `/plugin marketplace add mayberuk/iter8`, then `/plugin install iter8@iter8`.
- A standalone installer, `install.sh`, for machines without Claude Code, followed by `iter8 setup <host>`.
- An MIT licence, a third-party notices file for the bundled dependencies, a security policy, contributing notes and issue templates.

### Changed

- Installs no longer need the `gh` command.
- The README now addresses new users; the developer instructions moved to `CONTRIBUTING.md`.
